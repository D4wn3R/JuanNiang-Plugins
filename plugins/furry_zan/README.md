# furry_zan（爱点赞）

JuanNiang-Neo 版智能点赞插件

**【仅 QQ 可用】** 群聊 / 私聊中的点赞功能：赞我、每日定时自动点赞、取消自动、黑名单管理、时间设置与状态查看。

## 功能特点

- 🎯 **赞我**：任何人在群里发送 `/赞我`（或纯文本 `赞我`），机器人立即为其点赞
- 👍 **每日自动点赞**：好友发送 `/自动点赞` 订阅后，每天设定时间自动为其点赞
- 🚫 **黑名单管理**：管理员可添加 / 移除 / 查看黑名单，黑名单用户无法使用任何点赞功能（优先级最高）
- ⏰ **智能时间设置**：管理员可设置每日自动点赞时间，自动处理日期冲突
- 🔄 **一键测试**：管理员可随时 `/立即点赞`，自动修复日期问题
- 👥 **好友限定**：只有好友才能开启自动点赞，保护隐私
- 📢 **群通知**：自动点赞开始 / 完成时推送到指定群组
- 📊 **状态监控**：实时查看插件运行状态

## 命令列表

命令支持三种触发方式，效果一致：**斜杠命令**（`/赞我`）、**纯文本**（`赞我`）、**@机器人 + 命令**（`@机器人 /赞我` 或 `@机器人 赞我`）。

| 命令 | 权限 | 说明 |
|---|---|---|
| `/赞我` | 所有人 | 立即为自己点赞 |
| `/自动点赞` | 所有人（需为机器人好友） | 订阅每日自动点赞 |
| `/取消自动点赞` | 所有人 | 取消每日自动点赞 |
| `/添加黑名单 <QQ号>` | 管理员 | 加入黑名单，并自动取消其订阅 |
| `/移除黑名单 <QQ号>` | 管理员 | 移出黑名单 |
| `/查看黑名单` | 管理员 | 查看黑名单列表 |
| `/设置点赞时间 <HH:MM:SS>` | 管理员 | 设置每日自动点赞时间（支持 `HH:MM:SS` / `HH:MM` / `HH`） |
| `/立即点赞` | 管理员 | 立即执行一次自动点赞（测试用） |
| `/点赞状态` | 管理员 | 查看插件主要运行参数 |
| `/调试信息` | 管理员 | 查看详细运行状态与调度信息 |

## 配置项（Web 面板「配置」页签）

| key | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `enable_white_list_groups` | bool | `false` | 是否启用群聊白名单 |
| `white_list_groups` | list | `[]` | 允许使用点赞功能的群号列表（留空则全部群可用） |
| `auto_like_enabled` | bool | `true` | 是否启用每日自动点赞 |
| `likes_per_user` | string | `"20"` | 每次给每个用户点赞的次数（数字字符串） |
| `notify_groups` | list | `[]` | 自动点赞开始 / 完成时通知的群号列表 |
| `notify_delay` | string | `"1"` | 通知发送延迟（秒）。群通知为异步发送，此项保留仅为兼容原插件 |

> 订阅用户、黑名单、点赞日期、点赞时间等运行状态保存在插件目录 `data/state.json`，修改配置文件不影响已订阅用户。

## 定时调度说明

- **消息触发式调度（默认）**：任意消息到达时检查是否已到设定时间且今日未点赞，满足则自动执行，无需额外配置
- **CronJob 可靠调度（可选）**：本插件定义了 `on_cronjob`，可在 Web 面板为本插件创建每日 CronJob 定时触发，实现准点执行（重复触发无害，每日仅执行一次）

## 安装方法

1. 将 `furry_zan` 整个目录放入 `data/pluggins/`（或打成 ZIP 通过 Web「插件」页上传，也可从插件商店安装）
2. 在 Web「插件」页启用插件
3. 在「配置」页签按需修改参数

## 注意事项

- 点赞次数受 QQ 平台限制：单次调用最多发送 10 个赞，插件自动分批发送；频繁点赞可能触发风控
- 只有机器人的好友才能开启自动点赞
- 黑名单优先级最高：黑名单用户无法使用任何点赞功能
- 时间基于服务器本地时区
- 需要权限：`onebot11`（点赞 / 好友 / 发消息）、`file`（状态持久化）
- ⚠️ 修改 `main.lua` 后**必须**在 Web「插件」页对该插件**停用再启用**（toggle）或点「重载全部」，新代码才生效
- ⚠️ 若开启群白名单（`enable_white_list_groups`），非白名单群中命令会**静默忽略**（无任何提示），排查"没反应"时先检查此项
