# daily_analysis 群聊日常分析与总结

复刻自 `astrbot_plugin_qq_group_daily_analysis`，专为 **JuanNiang-Neo** 架构深度定制打造的智能群聊日常分析插件。

## 功能特色

1. **6 大板块合并转发卡片**：
   - 📊 **【群聊概况与活跃时段】**：统计前 24 小时群消息总量、发言人数、最活跃时段及峰值数据。
   - 🔥 **【今日核心话题】**：提取 1~N 个热门讨论主题、核心脉络与关键参与发言人（使用真实群昵称）。
   - 📖 **【群圣经 / 高光发言】**：筛选最具冲击力、反差感、槽点拉满的精彩语录，**彻底解决多行与带空行发言被切碎的 Bug**，100% 还原排版原貌。
   - 👑 **【群友特色头衔 / 活跃画像】**：为核心活跃发言者评选个性化荣誉头衔。
   - 🎭 **【聊天质量锐评与毒舌点评】**：多维度抽象剖析，**动态复用当前 Bot 自身的人格设定（如奶蛙口癖）**进行犀利吐槽与全群总结。
   - 📈 **【本次分析统计与模型】**：透明展示调用模型名称、服务商、总字符数及估算 Token 消耗。

2. **零图片依赖，极速轻量**：
   - 仅使用 OneBot 11 合并转发卡片（`send_group_forward_msg` / `send_private_forward_msg`），无需 T2I 浏览器渲染服务，无网络资源依赖，秒级直达。

3. **后台全功能可视化配置（无群聊命令干扰）**：
   - 多选群聊白名单列表配置。
   - 每日定时时间（默认 23:00，统计其前 24 小时消息）。
   - 话题数、圣经数、锐评维度数灵活可配（`-1` 为不限，`0` 为关闭该项）。
   - 插件管理页一键立即触发测试，并可指定将总结发送给指定群或指定好友 QQ。

4. **安全轻量的数据流**：
   - 建立专属消息表，默认保留 7 天轮转，分析后自动清理过期数据，永不膨胀。
